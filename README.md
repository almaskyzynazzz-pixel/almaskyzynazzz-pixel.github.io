VelvetChoco — статический сайт

Как запустить
- Откройте `index.html` в браузере (двойной клик) или запустите любой локальный сервер.

Страницы
- `index.html` — основной сайт с разделами: Главная, Магазин, Работы, Услуги, О нас, Контакты.
- `docs/index.html` — документация и раскадровка навигации с экспортом в PNG.

Технологии
- Чистые HTML + CSS + JavaScript. Без сборщиков и библиотек.

Бренд
- Цвета: какао коричневые с карамелью и золотым акцентом.
- Шрифты: Playfair Display (заголовки) и Inter (текст).
