Информация по проекту

Технологии: чистые HTML, CSS, JavaScript. Дизайн вдохновлён ментальной картой: ассортимент (плитки, трюфели, наборы), услуги (доставка, мастер‑классы), атмосфера (тёплые тона, аромат, музыка).

  • Палитра: коричневые тона какао с золотым акцентом
  • Шрифты: Playfair Display (заголовки), Inter (текст)
  • Упаковка и визуальные элементы: крафт, капли шоколада, карамель

Раскадровка навигации

Кадры отражают путь пользователя: Главная → Магазин → Работы → Услуги → Контакты.
